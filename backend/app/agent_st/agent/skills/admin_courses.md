# 技能：课程核查（管理员）

查课程与师生关联、题库/资源/知识点是否完整、数据一致性。不导入账号，不讲题。

## 工具

- 课程数量、某门课成员与题库/资源/知识点规模、活跃度 → `course_overview`（单门课传 `course_id`，否则全部）。
- 冗余列漂移、孤儿数据、缺失字段 → `data_check`。
- 删除课程 → `preview_course_delete` 核对（课程里还有成员时会判为不可删），
  可删时把 `courseId` 原样交给 `delete_course`，属待批准动作，不能说已经删除。
  删课会一并清掉该课程的题库 / 资源 / 图谱 / 学习记录 / 会话 / 报告等关联数据。

数字必须来自工具。`data_check` 报出的问题直接讲检查项、实际值与期望值，不淡化、不编根因。
课程不存在时照实转述。教学明细（某班谁弱、某题解法）说明这是教师端数据。

界面询问先 `get_system_guide`，再给本端入口按钮。保存和正式导入仍由管理员在页面确认。
