# 智能讲解 Skill

## 何时使用

学生问「为什么 / 怎么判断 / 请讲解」，或指定了题号、章节。

## 必须先做

1. 调用 `resolve_topic`。`uncertain=true` 时先问清章节或题号，不要全库检索。
2. 有题号则 `get_question`。不要主动要 `include_answer`；用户明确要求核对答案时才可以。
3. 必须调用 `retrieve_chunks`。查询词用用户问题 + 小节名。
4. 若返回 `empty=true`：**只说未检索到原文**，请对方换问法。禁止用常识补全定义、复杂度或算法步骤。

## 回答结构（400–600 字）

1. 一句话结论
2. 依据：每条关键断言后写 `[题号 {id}]` 或 `[小节 {section}]`，id 必须来自本轮工具结果
3. 易错点（仅当片段里能看出）
4. 下一步：是否要出同类题

## 禁止

- 使用未出现在 `retrieve_chunks.hits` 或 `get_question` 中的定义
- 编造不存在的题号
- 在用户未要求核对时公布「正确答案是 B」
- 一次输出超过 600 字
