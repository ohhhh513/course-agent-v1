# 教师 AI 联网与适度权限扩展：影响与实现方案

状态：项目所有者已确认实施，第一版及后续 DeepSeek 自动复用调整已完成。初版 Tavily 密钥留待之后配置；后续已用现有 DeepSeek 官方密钥完成真实搜索、教师问答及浏览器验收，无需额外申请 Tavily 密钥。

## 后续调整：复用已配置的 DeepSeek 官方密钥

项目所有者后续明确要求直接修改代码，使用已经配置的 DeepSeek 密钥打开联网能力。已检查当前模型接口为 `api.deepseek.com` 且模型密钥存在，不展示或复制密钥内容。

- 修改 `backend/app/services/teacher_web_search.py`、配置及示例：默认 `auto`，模型接口是 DeepSeek 官方地址且已有密钥时，调用固定的官方 `POST https://api.deepseek.com/v1/tools/search`，复用服务端 `LLM_API_KEY`；非官方模型接口不将其密钥转发给 DeepSeek。Tavily 保留为可显式选择的供应商。
- 继续由现有 `search_web` 工具调用服务；`/api/v1/ai/chat`、流式接口、legacy / SDK / MCP 调用关系及事件字段不变。仅对接供应商、结果字段适配和相关错误提示有变化，DeepSeek 查询长度遵守官方上限 128 字。
- 教师：保留联网备课入口，已有官方 DeepSeek 配置时无需再注册搜索平台。学生、管理员及定制技能试用仍无联网工具；隐私检查、任教课程校验、次数/超时限制保持。
- DeepSeek 返回的 `summary` / `snippet`、`url`、`date` 适配为现有工具结果，仍过滤不安全来源、不伪造日期。鉴权失败、余额不足、超时或不支持接口时明确说明，不悄悄切换其他付费供应商。
- 不修改数据库结构。回退可关闭 `TEACHER_WEB_SEARCH_ENABLED`，或显式选择 `tavily` 并使用原有 Tavily 配置；只回退本次服务与配置代码也不会影响原有数据。
- 验证：在数据库副本上完成自动供应商选择、密钥不会发往其他主机、错误处理、原有 Tavily 路径及角色回归，并实测当前官方密钥的真实搜索与教师问答。现有用户指令明确要求此次调整，沿用已经确认的教师只读联网权限范围。

## 1. 第一版功能范围

- 教师可以直接说「联网查一下……」，也可以从加号菜单选择「联网备课」。搜索公开教学资料、教学案例、技术文档及近期进展，回答附真实来源链接；资料中有发布日期时一并说明，不能把搜索时间当发布日期。
- 普通知识解释优先使用本课资料；明确要求联网、查询近期变化或寻找外部教学资源时再搜索。学情、预警等本地统计问题不联网。
- 教师可以围绕教学任务生成教案、课堂活动、讲授提纲、示例代码和课外拓展内容，不因本课教材缺少对应切片就直接拒绝；本课依据与网络补充分开说明。
- 第一版先开放公开信息读取和对话内教学内容生成。生成习题继续走现有草稿与审核流程；资源发布、发送通知、正式入库和删除不增加自动执行权限。
- 任教课程、学生成员校验及学生原始问答的隐私边界保持不变。学生端、管理员端和定制技能试用不获得联网工具。

## 2. 已确认的现状

- `tools/`、`flows/explain.yaml` 和教师技能目录目前没有联网搜索工具。
- 模型调用使用 OpenAI 兼容的 Chat Completions 接口，不能假设当前模型供应商支持某一家模型的内置联网工具。
- `registry` 已有模型可见工具过滤与执行前角色校验，可复用来限制联网工具仅教师可调用；模型不能自行提升角色。
- 前端教师菜单有班级学情、个体追踪、错题归因、备课出题、学情报告五种技能。各技能使用独立白名单，应保留职责边界，新增专门的联网备课技能。
- `analytics_tool_names()` 当前会将解释流中的教师专用工具概括为学情查询。新增联网工具时需区分两者，避免搜索失败被误当成有效教学依据。

## 4. 接口与调用方影响

- 复用 `POST /api/v1/ai/chat` 与 `POST /api/v1/ai/chat/stream`，不要求旧调用方提交新增字段；角色仍由服务端登录身份确定。
- 教师聊天、legacy / SDK 运行层，以及导出同一工具注册表的 MCP 是主要调用链。MCP 若采用同一解释流，也必须保持教师限定与服务端搜索配置校验。
- 保持 `session / text / think / tool_start / tool_end / draft / citations / action / error / done` 事件名称和字段不变。
- 网络来源以回答中的真实 Markdown 链接呈现，工具过程复用既有工具事件；不把网页伪装成本课教材切片或改变原有课程引用结构。
- 日志复用 `chat_messages.tool_log`。不增加表、列、字段类型或迁移，不把搜索结果自动写入课程资源。

## 5. 教师与学生分别看到什么

- 教师：多一个「联网备课」入口；联网时有搜索工具过程，回答有可点击来源；可以提教案、教学设计和相关拓展要求。搜索不可用时保留本课查询能力并明确说明。
- 学生：原有技能、课程依据、只读工具和操作确认保持现状；即使伪造技能编号或工具名也不能获得联网或教师工具权限。
- 管理员：不因此获得教师数据视角，不增加治理写权限。
- 定制技能试用：继续使用原有只读课程工具，不将联网能力自动扩散到学生可发布的定制技能。

## 6. 合理边界与故障处理

- 仅向搜索服务提交公开教学主题查询，不附带完整对话、附件、学生姓名学号、联系方式或本地学情记录。服务端校验敏感标识与查询格式，拦截不适合外发的查询。
- 网页内容只作为资料，不能覆盖系统规则、触发写操作或授予工具权限；仅呈现有效 HTTP(S) 来源，不执行网页指令，不增加任意网址抓取、内网访问或账号登录能力。
- 搜索默认取少量结果，设置每轮次数和超时；搜索失败或无结果时如实说明，不宣称已完成检索，不凭空生成来源链接。
- 启用范围是备课与教学支持，不能据此查看非任教课程、学生原始对话、平台账号治理或自动改变业务数据。
