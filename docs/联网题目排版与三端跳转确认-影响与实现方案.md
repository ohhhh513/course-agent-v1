# 联网题目排版与三端跳转确认：影响与实现方案

状态：用户已确认，前端与后端实施完成。已验证真实搜索→读取来源→题卡→历史恢复，以及三端确认/取消；题图加载成功/失败使用明确的界面测试图验证。

## 本次故障修复影响

用户实际请求「帮我网上找个线性表的题」出现反复校验失败。本次在已确认的原题整理范围内修复：来源与证据统一做无损排版规范化并映射回真实原文片段，数字、比较符及题意差异仍拒绝；未要求的答案只隐藏，不使合法题目失败；同轮整理连续失败达到上限后停止重试，提供明确结束提示，有题卡时显示题卡提示。调用方仍为现有教师 read_web_page / prepare_web_question 与 legacy / SDK 聊天链路，学生端无新增能力；事件、数据库与缺图规则不变。可回退本轮匹配与终止逻辑，已有题卡和数据不需迁移。测试在库副本复现用户原句及原先失败参数，不在真实库验证写入。

## 1. 联网题目与题图

- 当前教师联网搜索只返回标题、摘要、来源，不能据此确认原题是否缺图。新增受限的原文读取与题目整理工具，使用已接通的 DeepSeek 官方能力；只读取本轮真实搜索返回的公开来源，不新增任意地址抓取、登录网站或内网访问功能。
- 模型先读取原文，再将题目整理成受校验的数据：题目名称、题面、题型、选项、题图及来源。共享前端渲染成独立题目卡片，题面与选项分区、代码与表格保留格式、来源单独显示；答案解析只在用户需要时提供。
- 图片必须来自该来源原文，并能与该题对应，不能使用搜索结果封面、广告图或随意找相似图片。纯文字题保留；题目依赖图但原文中找不到对应图片、图片不能加载或原文无法完整获取时跳过整题，不用缺图提示或占位图充数。
- 前端先加载校验题图，成功后展示完整题卡；任何必要题图加载失败时移除该题卡，提示本次跳过了不完整题目，不输出残缺题面。不给未核实的图片和题目提供自动入库能力。
- 学生与管理员不因此获得联网工具。当前联网找题能力仍仅教师可用，展示组件可以共享。数据复用现有消息与工具日志，不新增表、列或迁移。

## 2. 所有端的窗口操作必须经点击选择

- 学生、教师、管理员统一规则：AI 回答涉及页面、弹窗、资源详情、练习或报告等入口时，先展示目标与「打开／继续」「取消」选项；用户不选择就不导航、不打开窗口。即使本轮已经说「打开」，也需要点击这次确认。
- `prepare_ui_action`、`suggest_action`、旧消息中恢复的入口都遵守这条规则。收到旧的 `auto=true` 也不再自动执行；历史重新加载不执行。
- 确认前保留角色、用户、课程、会话与未保存内容检查；等待附件或异步准备期间切换账号、课程、会话，旧确认失效。取消不触发跳转或后续生成操作。
- 生成报告或题目等现有功能保留，但确认卡片必须清楚写明是否会生成内容并打开详情；点击确认后才执行原有流程，保留现有重复执行保护和写入审批，不扩大角色权限。
- 保持 `session / text / think / tool_start / tool_end / draft / citations / action / error / done` 的名称与字段不变；旧 `auto` 字段保留兼容，不能再作为无点击跳转的授权。

| `chat_skills.py`、`flows/explain.yaml`、legacy / SDK / MCP 工具注册 | 仅教师联网技能与教师通用解释流增加所需只读工具，学生和管理员保持过滤 |

| `assets/js/shared/agent-chat.js`、`agent-ui.js`、样式与缓存 | 题目卡片、必要题图加载与失败跳题；三端确认/取消、阻止自动执行与历史重放，保留已有操作校验 |

## 4. 用户可见变化

- 教师：网络题目排版整齐，依赖图片的题会连图展示；无法完整取得的题不会作为例题输出。任何界面操作都先询问。
- 学生：原有答疑与只读权限保留；打开练习、资源、报告等须点击确认，取消后留在原界面。
- 管理员：现有治理查询与写入审批保留；打开管理页面或弹窗也须点击确认。

## 5. 失败与回退

- 原网页不可用、无法辨认题目或图文对应关系时跳过该题，明确说明没有找到可完整展示的题目，不伪造内容或图片；回退到建议换来源，不自动编造替代题冒充网络原题。
- 新题目整理路径可停用并回退到普通资料搜索；消息与数据库结构不需迁移。
- 跳转确认属于用户最新的明确规则，回退题目展示时仍保留确认门槛，不恢复未经点击的自动跳转。

## 6. 验证

先完成前端确认，再验证；经确认后实施后端阶段与题目展示，完成一阶段再进入下一阶段。测试写入仅在库副本。

- Python 语法、工具角色、路由、MCP、学生真实模型冒烟及教师实际问答。
- 网络题目：纯文字、单图、多图、缺图、坏图、图片来源不符、相对 URL、表格/代码、网页指令与 HTML 不执行，不能靠摘要拼凑缺失题面。
- 三端：未点击无跳转，取消无操作，确认后才执行；旧 `auto=true` 计划与历史恢复同样拦住；切换课程/用户/会话、未保存表单及附件异步恢复不会误执行。
- 浏览器硬刷新验证题卡、图片与确认/取消，记录实际点击和结果；修改技能说明后在库副本上真实问答并记录原文。
