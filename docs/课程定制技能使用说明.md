# 课程定制技能使用说明

定制技能基于现有学生技能配置学习方式。教师可指定用途、处理步骤、回答格式和示例；实际课程数据访问、工具权限和操作确认仍由系统控制。

## 教师创建与发布

1. 登录教师端，选择要配置的课程，打开「智能助手」。
2. 点击输入框加号 →「管理定制技能」，每次打开默认进入新建草稿；编辑已有技能时从左侧列表选择。
3. 选择配置方式：推荐新手使用「引导式配置」；熟悉教学要求时也可选「自由编写」。
4. 完成下方配置，点击「保存草稿」。学生此时还看不到该技能。
5. 在右侧输入测试问题，点击「发送」，或按 Enter；Shift+Enter 换行。发送时自动保存当前编辑内容并使用这份草稿，顶部显示对应技能名称。可以连续提问；修改草稿后会重新开始试用。
6. 确认效果后点击「发布」。有未完成的必填项时，会跳到对应步骤并标红提示；配置完整时保存当前内容并发布，学生重新打开加号菜单即可选择。

## 引导式配置：四步完成

1. **选教学模板**：一步一步引导、把概念讲明白、陪学生分析例题、带学生复盘错题、解释个人学情、安排复习与练习、帮学生找资料。模板预配完整流程，新建时不自动选择，技能名称也需要自行填写。
2. **填学习目标**：「给哪些学生用」从学习基础和复习场景中选择；学习目标自行填写，示例显示在输入框占位提示中，不是已填写内容。范围可留空，跟随学生本轮提问。
3. **选辅导方式**：怎样教、一次讲多少、遇到题目怎样处理，默认均为「请选择」，需要主动选择；「更多教学细节」例外，保留推荐值，可进一步调整难度、资料依据、信息不足处理、理解检查、回答结构、语气、长度、补充要求和问答示例。
4. **预览与试用**：系统把选项整理成可阅读的规则，可先核对，再到右侧用实际问题试用；底部「保存草稿」与「发布」始终是两个独立按钮。

「上一步」「下一步」固定在编辑区底部。红色 `*` 表示必填；点击下一步时，当前步骤有未填写的必填项会标红并阻止继续，填写后红框立即清除。进度条跳步、预览、保存和试用也执行必填校验。

新建时输入框留空、示例只在框内作灰色提示。从左侧选择已保存技能时保留原值，原有的自定义学生对象也会保留，不会被清空。桌面面板已放大，编辑区和对话区各自滚动；窄屏会纵向排列。

### 填写示例

| 页面问题 | 可以这样填或选 |
| --- | --- |
| 给哪些学生用？ | 选择「基础较弱、需要更多提示的学生」 |
| 主要围绕哪一部分？ | 栈和队列；也可留空 |
| 希望学生最后能做到什么？ | 能说出两者差别，并判断一个生活中的例子 |
| 主要怎样教？ | 多问少讲，逐步引导 |
| 一次讲多少？ | 每轮只推进一步 |
| 遇到题目怎样处理？ | 先思考，再讲思路 |
| 还有什么特别要求？ | 优先用校园生活中的例子，不一次给出全部推导 |

## 自由编写：直接写完整要求

选择基础技能，再直接编写用途、处理步骤、回答格式和示例。新建时基础技能为「请选择」，正文留空；带红色 `*` 的名称、基础技能、用途和步骤必须填写。每个输入框都有填写提示；可以从完整的引导式配置转为自由编写，在已生成的文字上继续修改，也可以清空正文自己写。

旧技能默认以自由编写打开，原文字不自动改写。自由模式的手写内容和模式会被保存；切换回引导式会用模板和填空重新生成正文，因此会先要求确认，取消不会覆盖已有文字。编辑器选项仅用于恢复界面，模型以最后保存的文字规则为准。

例如：名称「循序渐进讲题」，基础技能「课程答疑」，步骤「先查本课资料；每次只给一个提示，等学生回答后继续」，格式「简短解释 + 一个引导问题」。

试用只查课程资料与题目，不读取真实学生个人学情或执行页面操作。学情诊断等依赖学生个人数据的效果，需要由学生在发布后使用自己的账号验证。试用需要可用模型；出现配置或请求错误时会明确提示。

试用回答支持 Markdown 标题、加粗、列表、行内代码、代码块、引用和表格，长回答在试用区内滚动；问题按教师输入的原文显示。

## 修改与停用

- 保存修改只更新草稿，学生仍使用上次发布的版本；再次发布才替换学生可用版本。
- 点击「停用」后，学生不能再发起使用该技能的新请求；保留草稿和发布内容，教师可重新发布自己的未封禁技能。
- 多个页面同时修改时，旧页面会提示版本冲突并保留当前输入，请重新打开查看最新内容后决定如何修改。
- 教师只能管理自己在当前任教课程创建的技能；切换课程后需重新打开管理面板。

## 学生使用

选择课程后，打开「AI 智能答疑」，点击输入框加号并在列表中找到教师发布的技能，也可搜索名称或描述。选中后正常输入问题即可；点击技能标签的叉号恢复普通提问。

列表较长时可在菜单内滚动。重新打开菜单会刷新课程技能，已停用的技能会被移除。内置技能继续保留。

## 管理员治理

管理员端「智能助手」→ 输入框加号 →「管理定制技能」，可按技能名称、课程或教师搜索并停用。管理员停用的记录不能由教师直接重新发布。

## 数据与部署

无需迁移数据库。更新代码后重启服务，再强制刷新三端页面，使管理入口和接口同时生效。定制定义随现有业务数据库备份；不写入仓库内置技能文件，也不保存在浏览器本地。
