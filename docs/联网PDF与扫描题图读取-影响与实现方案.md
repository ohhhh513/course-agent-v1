# 联网 PDF 与扫描题图读取：影响与实现方案

状态：用户已确认并完成实施。已验证真实教师搜索→出版社 PDF→单题原图→题卡，以及扫描版 OCR、浏览器硬刷新与历史恢复；验证使用库副本。

## 已确认的问题

- `read_web_page` 每轮最多尝试两次，读取失败同样占次数；两个不可读来源足以让整个取题流程提前结束。
- `teacher_web_search.fetch_page` 只调用 DeepSeek 正文读取，没有下载 PDF、提取文字、渲染页面和识别扫描页的分支。
- 上传附件的 `file_text._read_pdf` 使用 pypdf 提取文字，未接入联网读取，也不具备扫描页 OCR。教师导入中的图片 OCR 是另一条独立流程。
- 上一轮修复的是题卡原文校验及重复失败终止，没有补齐 PDF 和扫描图读取能力。不能把本地工具缺失描述成 AI 或 PDF 本身无法处理。

## 拟实现行为

1. 保留普通网页正文读取。遇到本轮搜索结果中的公开 PDF，下载并验证实际文件类型，优先提取原生文字；扫描页或文字不足的候选页渲染成图片，再用本地 OCR 获取文字和坐标。
2. 使用现有 pypdf；新增 pypdfium2 页面渲染、RapidOCR 与 ONNX Runtime CPU 识别依赖，验证 Python 3.11 与服务器安装方式，固定实际验收的兼容版本。OCR 模型在部署时准备，不要求教师安装桌面软件，不引入新的付费模型密钥。
3. 页面渲染保留原始图形，包括 PDF 内的矢量图。能可靠确定题目边界时保存题目区域原图；只能确定整页时提供清楚标注的原页预览与页码，不把其他题、答案或整页误标成独立配图。无法可靠分离和隐藏答案时换题，不自动重画或编造题图。
4. OCR 用于检索和定位，保留原页作为核对依据；不把存在明显识别问题的公式、下标、队列指针等内容强行整理成确定题面。图文无法对应时换来源。
5. 默认每轮最多尝试 6 个不同来源，总读取预算 90 秒；同来源重复读取复用缓存。失败来源不会占用成功题卡限额，但占总尝试和时间预算。单 PDF 默认 15 MB，每轮最多渲染识别 8 页；优先搜索命中页、链接页码和可提取文字定位的候选页。达到预算明确说明已尝试情况，不要求用户再发送一句话才能换来源。
6. 题图存储在现有 resources 下的独立联网题图缓存目录，以内容哈希命名；记录来源与页码映射。只接受服务端生成并可核验的本地图片引用，不提供任意 URL 图片代理。历史题卡仍能加载这些原图。

## 接口、调用者与角色影响

| 代码/接口 | 影响 |
| --- | --- |
| `services/teacher_web_search.py` 与新 PDF 读取服务 | 搜索结果读取增加受控 PDF 下载、文字与页面图像处理；直接下载不携带模型密钥，校验公开地址、DNS 和重定向目标，限制体积、页数、时间 |
| `agent/tools/web_questions.py` | `read_web_page` 返回可核对的页码、正文和服务端生成图片引用；`prepare_web_question` 验证题图与原页关联，保留原有网页来源验证 |
| `skills/teacher_web_research.md` 及配置/依赖 | PDF 不再直接放弃，当前回合自动换来源；调整来源预算并记录真实失败原因，保留整理失败终止保护 |
| 现有聊天接口及前端题卡 | 复用 `/api/v1/ai/chat`、`/api/v1/ai/chat/stream` 和题卡工具日志；共享前端支持受控本地题图、PDF 页码与原页预览 |

教师可获得 PDF 原题及对应原图；学生和管理员不新增联网工具或写权限。窗口操作仍须用户点击确认。数据库不加表、不加列，SSE 事件名称和字段保持原样，页码与图片引用复用现有 JSON 元数据。

## 失败与回退

网页失败后在剩余预算内换来源；下载失败、加密/损坏文件、OCR 不可辨识或图文无法核对时跳过，不冒充已看过原页。依赖或 OCR 模型未安装时明确提示部署缺失。提供配置关闭 PDF/OCR 分支，可回退到普通网页搜索，已有数据无需迁移；保留已产生图片以免历史断图。

## 验证

分阶段实施：先完成 PDF 读取与图像定位并验证，再接题卡与前端展示。使用库副本验证原生文字 PDF、扫描 PDF、矢量图、跨页、识别失败、坏文件、读取超时与来源限制；真实教师发送「来个有图的队列的题」，核验来源、页码、题图与浏览器历史恢复。执行 Python 语法、角色、路由、MCP、学生与教师真实模型冒烟，记录真实回答和依赖准备方法。
