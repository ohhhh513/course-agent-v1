## 关键事实速查

- **技术栈**：原生 HTML/CSS/JS + ECharts，无框架、无构建。
- **数据来源**：所有取数走 `API.*`；`api.js` 中 `config.mode = 'http'`，**默认直连真实后端**（`/api/v1`），页面零改动。
- **统一信封**：`{ code, message, data, traceId }`，成功 `code=0`，前端读 `data`。
- **鉴权**：`Authorization: Bearer <JWT>`；登录 `/auth/login`，当前用户 `/auth/profile`。
- **角色**：`student`（学生端 `student.html`，7 视图）/ `teacher`（教师端 `teacher.html`，7 视图）。
- **首页**：`index.html` = 登录页；`forgot.html` 找回密码；`home.html` 产品介绍（可选）。
- **Mock 已下线**：早期 `assets/js/mock/data.js` 与 `mode:'mock'` 已移除，前端现在只消费真实后端接口。

## 文档与代码一致性约定

- 接口文档是**唯一接口真相源**，由 `assets/js/api.js` 的注释契约同步维护。
- 后端返回的每个接口 `data` 字段结构必须与 `数据模型与Mock说明.md` 中列出的结构**严格一致**，前端才能正常渲染。
- 如后端实现与文档冲突，以**本文档集合**为准，并请同步更新 `接口文档.md` / `数据模型与Mock说明.md`。

## 本地运行

```bash
cd course-agent
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

> 联调时建议直接启动后端（见根目录 `README.md`），由后端在同一端口挂载前端静态文件，避免跨域。
