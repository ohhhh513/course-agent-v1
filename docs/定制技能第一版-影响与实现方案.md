# 定制技能第一版：影响与实现方案（2026-10-27）

## 引导式配置增量（2026-10-27）

- 教师可选择「引导式配置」或「自由编写」。引导式按选模板、填写目标、选择辅导方式、预览与试用分步完成；提供概念讲解、循序引导、例题陪练、错题复盘、学情诊断、练习规划和资料导航模板，选项带推荐值、解释和示例。
- 不新增接口。`POST /teacher/skills` 和 `PUT /teacher/skills/{id}` 在原六项文字字段之外，增加可选 `builder` 编辑器配置，保存模式、模板和填空选项；由同一教师编辑器调用。省略该字段的旧请求继续有效。
- `builder` 复用现有 `data_json`，不加表、不加列；服务端校验版本、字段、枚举和长度，不能携带角色或工具权限。
- 发布、试用和学生聊天继续使用生成后的文字规则；后端解析技能时排除编辑器元数据，避免自由编写内容与旧填空配置同时进入模型。学生端技能选择和权限均保持原样。
- 教师重新打开草稿时能恢复原来的选项；旧草稿默认以自由编写打开，不自动覆盖。切换至引导式重新生成时明确提示，自由编写保留完整文字编辑能力。
- 修改范围：前端编辑器、模板配置、样式、缓存版本；后端仅扩展草稿请求及 JSON 校验和模型输入中的元数据排除，补充兼容性和权限测试。
- 回退：可停用新配置记录，再一起回退编辑器及可选配置支持。原有名称、用途、步骤、回答格式、示例仍是完整文字，既有技能和数据库结构无需迁移。

## 范围

- 教师在当前课程创建面向学生的定制技能，以课程答疑、错题复盘、学情诊断、练习教练或资源导航为基础，填写名称、用途、步骤、回答格式及示例。
- 草稿可编辑、保存和试用；发布时生成版本快照。编辑草稿不影响学生正在使用的已发布版本；教师可停用自己的技能，管理员可查看和停用课程定制技能。
- 学生只能看到已加入课程中已发布且未停用的技能；不能创建、修改、发布或试用草稿。内置技能继续可用。

## 接口和调用方

| 接口 | 调用方 | 用途 |
|---|---|---|
| `GET /api/v1/skills` | 学生聊天加号菜单 | 当前课程已发布的学生技能 |
| `GET /api/v1/teacher/skills` | 教师技能管理 | 当前课程本人技能及可选基础模板 |
| `POST /api/v1/teacher/skills` | 教师编辑器 | 创建草稿 |
| `PUT /api/v1/teacher/skills/{id}` | 教师编辑器 | 保存草稿，带版本号防止覆盖他人或旧页面修改 |
| `POST /api/v1/teacher/skills/{id}/trial` | 教师试用面板 | 对已保存草稿进行真实问答试用 |
| `POST /api/v1/teacher/skills/{id}/publish` | 教师编辑器 | 将当前草稿发布为学生可用的版本 |
| `POST /api/v1/teacher/skills/{id}/disable` | 教师技能管理 | 停用自己的技能 |
| `GET /api/v1/admin/skills` | 管理员技能管理 | 查看定制技能及课程归属 |
| `POST /api/v1/admin/skills/{id}/disable` | 管理员技能管理 | 停用技能，教师不能直接恢复被管理员停用的记录 |

现有 `/ai/chat`、`/ai/chat/stream` 继续接收 `skillId`；新增对服务端定制技能 ID 的识别。管理员对话流和现有流式事件名称、字段保持不变。

## 后端修改点

- 新增技能管理服务、路由，并在 `main.py` 注册；所有身份与课程归属由登录账号和成员关系验证。
- `chat_skills.py` 解析已发布技能，工具取基础技能、当前任务流和实际角色授权的交集；用户填写的文本不能添加工具或覆盖服务端授权。
- `loader.py` 先加载基础技能，再附加定制说明，保留课程隔离、数据依据、学生只读及页面跳转确认等系统约束。
- legacy 与 SDK 两种运行层均传入真实调用者身份及课程，加载本轮确定的技能快照；停用、退课或跨课请求不得继续使用。
- 教师试用只使用课程资料、题目等只读能力，不读取真实学生个人数据、不执行页面动作；试用记录与学生对话隔离，不写学生进度。
- 账号删除服务补充清理该教师拥有的定制技能；现有课程删除按 JSON `courseId` 清理课程定制技能。

## 数据存储

- 复用既有 `teacher_class_data`：`data_type=custom_skill`、`data_key=随机技能 ID`、`class_id=NULL`，定义保存在 `data_json`。
- JSON 中保存 `ownerId`、`courseId`、草稿、已发布快照、版本、停用状态及时间信息；与既有账号资料、考试、学情聚合类型隔离。
- 不加表、不加列、不修改字段类型、不写迁移。读取列表不写入数据库，写入使用事务和并发版本校验。

## 师生端变化

- 教师：智能助手加号菜单出现「管理定制技能」，可编辑、试用、发布和停用本人的课程技能。
- 学生：加号菜单在原有技能之外增加课程发布的技能；新建、停用或发布新版本后重新加载菜单可见；每个新请求重新校验技能可用性，并固定本轮使用的发布快照。
- 管理员：加号菜单增加定制技能管理，可查看课程归属并停用；不进入师生教学任务流。

## 回退

- 先停用相关定制技能，即可停止新请求使用，内置技能仍可用。
- 代码回退时移除新增路由及动态技能加载，恢复原固定菜单；新增 JSON 记录可保留，旧代码不会按此类型读取。
- 不需要数据库结构回退；保存失败回滚事务，版本冲突返回 409，保留用户编辑内容供重新确认。

## 验证

- 所有业务写入测试使用数据库副本，前后对比数据库结构，覆盖师生权限、跨课、非作者编辑、发布与草稿隔离、停用、并发冲突及删除清理。
- 检查 legacy 和 SDK 的技能加载与工具白名单；真实模型验证定制要求生效，并记录实际回答与运行层。
- 检查管理弹窗、菜单异步刷新、课程切换和失败提示；运行仓库的语法、角色、路由、MCP、智能答疑冒烟检查。
