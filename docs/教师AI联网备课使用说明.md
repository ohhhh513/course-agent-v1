# 教师 AI 联网备课

教师端「智能助手」→ 输入框加号 →「联网备课」。也可在未选择技能时直接说「联网查找……教学资料」。已选班级学情、个体追踪等技能时，切换到联网备课再查外部资料。

可以询问公开教学资料、课堂案例、技术文档和近期进展；也可要求生成教案、课堂活动、讲授提纲、示例代码与教学拓展。普通知识优先查询本课资料，教学设计不再因为缺少本课教材切片就直接拒绝。

例如：

- 「联网查一下 Python 官方文档里 deque 的用法，给我两个队列教学示例并附来源。」
- 「设计一份 10 分钟的栈与队列课堂活动，面向刚接触这门课的学生。」
- 「查找适合本课的可视化教学资源，说明每个资源适合讲什么。」

联网结果有标题、摘要和来源链接；点击链接在新标签页打开，历史对话中仍可查看。引用来自搜索摘要时不代表已经阅读全文；没有公布日期的资料不会自动补一个发布日期。

## 网络题目与配图

查找练习题时，AI 会先搜索、读取原网页，再整理为独立题卡。题面、选项、代码/表格、题图及来源分区显示，清理网页转义字符；不根据搜索摘要拼凑题目。纯文字题正常保留，默认不显示答案，要求解析时才提供。

只有原题片段中的对应配图才可采用。题目依赖配图但无法提取完整题图时跳过，不用封面、广告、相似图片或生成图片代替；图片成功加载后才显示整题，任何必要配图加载失败都会移除该题。无法读取或不能确认完整性的来源也跳过。

题图默认适应题卡宽度，不再受聊天缩略图的 220px 限制。图片上方可拖动滑块或点击加减调整至 50%～300%，放大时阅读框高度保持稳定，超宽在底部左右滚动、超高在右侧上下滚动，「适应宽度」恢复默认。双击图片、图片聚焦后按 Enter，或点击「查看大图」打开居中预览；大图支持 50%～400% 缩放、滚轮缩放和鼠标拖动，「适应窗口」或双击恢复完整显示。按 Esc、点击关闭或遮罩可退出，不跳转新页面。

网页正文使用 DeepSeek 官方 Fetch；本轮搜索结果中的 PDF 可直接下载，优先提取文字，扫描页会渲染图片并在本地 OCR。PDF 矢量图随原页一起保留；能确认边界时截取单题，不能切分时仅采用可核对且无答案泄露的原页预览，不用新画的图替代。题卡显示 PDF 文件页码，原页中的书内页码可能不同。扫描识别文字可展开查看，以原图为准。

默认每轮可尝试 6 个不同来源，实际读取总预算 90 秒，最多识别 8 个 PDF 候选页，单 PDF 上限 15 MB，文档索引最多 300 页；最多整理三题。失败后当前这轮继续换来源，重复来源走缓存；不会读两次就要求用户再问一轮。只接受本轮真实搜索来源，不提供任意网址代理。题卡随现有工具日志保存，重开历史会话可恢复，不会自动导入正式题库。加密且不能空密码打开、损坏、超限、识别不清或跨页无法可靠切分的来源仍会跳过。

首次读一份 PDF 最多渲染 4 个候选页，优先习题栏目、问句与填空，给其他来源保留页数；剩余预算内支持指定同一来源的其他文件页，每次补读 1 页并保留已读内容。相同页不重复消耗预算。

## 连续找题与去重

默认把重复提交的找题要求视为找新题。同一教师、同一课程近 30 天最近 200 条含题卡消息参与比较，新建会话也优先跳过近期发过的题；不会读取其他教师或课程的历史。标题、UUID、题号前缀、空白与选项顺序不同不能把旧题变成新题。题干条件、数字、选项及真正不同的题图保持区分。

工具发现重复后会在当前回合继续找，同页/同一 PDF 的其他题仍可选；不会整本排除。重复不计入原文错误次数，也不会为了通过检查而改写原题。明确说「再看上一道题」「讲解上一题」时可引用原题，不强行换掉对象。预算内没有完整且未用过的新题时如实反馈；不把旧题包装成新题，也不保证所有外部来源都能读取。

## 三端界面操作确认

学生、教师、管理员的 AI 回答只要涉及打开页面、弹窗、练习、资源、报告或出题操作，都先显示目标和「确认 / 取消」。**即使本轮已经说“打开”，也仍需要点击确认。** 未点击或取消时留在原界面；报告和习题生成入口确认后才开始执行，后续业务保存、发送、导入等继续使用原有确认。

旧消息中的 `auto=true` 不再自动执行，历史重新加载也不会重放。等待附件或操作准备时改变账号、课程、会话或取消，旧操作失效。

## 服务端配置

1. 在项目使用的 Python 环境中更新 `backend/requirements.txt`。默认自动识别供应商：**已有 DeepSeek 官方地址与模型密钥时，直接复用它们联网，不需要另外申请 Tavily 密钥**。
2. 现有 `LLM_BASE_URL=https://api.deepseek.com`（也支持 `/v1`）和 `LLM_API_KEY` 保留即可。可在 `backend/app/.env` 调整以下选项，真实密钥只保留在服务端，不提交 Git：

```dotenv
TEACHER_WEB_SEARCH_ENABLED=true
TEACHER_WEB_SEARCH_PROVIDER=auto
TEACHER_WEB_SEARCH_TIMEOUT=15
TEACHER_WEB_SEARCH_MAX_RESULTS=5
TEACHER_WEB_SEARCH_MAX_CALLS=2
TEACHER_WEB_READ_MAX_SOURCES=6
TEACHER_WEB_READ_BUDGET_SECONDS=90
TEACHER_WEB_PDF_ENABLED=true
TEACHER_WEB_PDF_MAX_MB=15
TEACHER_WEB_PDF_MAX_PAGES=8
TEACHER_WEB_QUESTION_DEDUP_ENABLED=true
```

3. PDF/OCR 部署准备：在应用 Python 环境运行 `python dev_tools/prepare_web_pdf.py`，首次需要联网准备公开 OCR 模型与字体。正式请求只使用已准备的本地资产，不要求教师安装桌面 OCR 软件，也不用另申请视觉模型密钥。当前本机 test1 已完成安装与准备；不把环境名写死在项目启动脚本里。
4. 重启后端，教师页面按 Ctrl+F5 强制刷新。

设置 `TEACHER_WEB_PDF_ENABLED=false` 可单独关闭 PDF/OCR 路径。生成的公开原题截图保存在 `resources/web-question-pdfs/`，应随服务资源持久化并允许页面服务读取；不要删除已被历史题卡引用的图片。下载、渲染和识别在独立进程内施加整体超时，不向原网站发送模型密钥；跳转目标与实际连接的 DNS 地址也须为公网。

设置 `TEACHER_WEB_QUESTION_DEDUP_ENABLED=false` 并重启，可停用新增的近期题卡去重；不删除任何历史数据。

查询主题为 2～128 字。结果数最多 5 条，每轮次数最多 3 次，超时限制 3～30 秒；超出范围的配置会按边界截断。没有可用对话模型时说明处于演示模式，不生成伪联网回答。鉴权失败、余额不足、限流、超时和空结果均明确反馈，不编造来源，也不会因请求失败自动改用其他供应商。

`TEACHER_WEB_SEARCH_PROVIDER` 可选：

- `auto`（默认）：官方 DeepSeek 地址且已有模型密钥时使用 DeepSeek；否则使用已配置的 Tavily。
- `deepseek`：明确使用 DeepSeek，要求已有官方模型地址和密钥；第三方中转密钥不会被发给 DeepSeek。
- `tavily`：明确使用 Tavily，另配置 `TAVILY_API_KEY`。需要时才申请此密钥，不进行匿名搜索。

官方服务与密钥由部署人员管理，搜索有独立计费规则，以服务商账户为准。官方说明：[DeepSeek 搜索](https://api-docs.deepseek.com/guides/search/)、[Tavily 搜索](https://docs.tavily.com/documentation/api-reference/endpoint/search)。

## 权限范围

- 仅当前任教课程中的教师可调用。学生、管理员和学生定制技能及草稿试用不会获得联网工具。
- 只发送简短公开教学主题，服务端会检查学生姓名、账号、学号、联系方式和学情标识；不附带完整对话、附件或学生记录。不要把私有学生材料当作搜索关键词。
- 学情仍查询当前课程数据库，不能拿网络资料编造班级数据或查看其他课程学生。
- 网页是参考资料，不能授予权限或触发系统操作。第一版不新增任意网页抓取、网页登录或内网访问功能。
- 生成教学建议只在对话中显示；正式出题、资源发布、通知发送、入库、删除和页面跳转继续遵守已有确认规则。

停用时设置 `TEACHER_WEB_SEARCH_ENABLED=false` 并重启，本课查询和学生端继续使用。无需数据库迁移。

## 验证

`dev_tools/check_teacher_web.py` 使用数据库临时副本验证权限、查询保护、Tavily SDK 参数、来源过滤、限额、失败反馈及 HTTP/SSE；加 `--live` 会自动使用实际供应商，以教师 `wangjg` 调用真实模型与搜索。`dev_tools/check_deepseek_search.py` 使用 MockTransport 检查 DeepSeek 请求、自动选择、密钥发送边界与错误反馈；`dev_tools/check_teacher_web.js` 检查来源链接与教师历史消息显示。

`dev_tools/check_web_pdf.py` 验证原生 PDF、无文字层扫描 PDF 的真实 OCR、矢量图保留、答案边界、缓存、体积限制、内网 DNS/跳转、超时和空密码可读文件；中文测试素材默认使用 Windows 黑体，生产读取不依赖此系统字体。`dev_tools/check_web_questions.py` 验证 PDF 原图/页码关联及失败来源切换。真实验收可运行 `python dev_tools/check_teacher_web.py --live --require-web-question --question "来个有图的队列的题"`，必须实际生成带图题卡才通过，不把 HTTP 成功当作取题成功。

初版仅接入 Tavily，因未配置 Tavily 密钥只完成模拟搜索展示；后续改为默认复用 DeepSeek 官方配置，已用项目现有密钥实际调用官方搜索并获得网页结果，教师真实模型问答及浏览器中的发送、来源链接、历史重新加载也已通过。Tavily 可选路径仍通过离线回归，未使用真实 Tavily 密钥验收。
