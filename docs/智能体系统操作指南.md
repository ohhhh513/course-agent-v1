# 智能体系统操作帮助（2026-10-09）

## 用户会看到什么

三端智能体可回答本系统的页面、面板、页签、小按钮和弹窗操作问题。询问「怎么做、在哪里」时说明必要步骤并提供精确入口按钮；明确说「帮我打开、我要做、把以下内容填入」时自动打开已登记的页签、弹窗或对象，并回填允许的字段和本轮附件。

这些说法只是例子，智能体按完整语义和最近对话承接对象，不要求固定口令。例如先说「我想学习哈希表」，再问「那他的资源在哪里」「这个有没有课件可以看啊」，应提供哈希表节点「关联资源」页签的真实按钮，保持在对话页；说「带我去看它的资料」才自动打开。入口本身不证明已有课件，资源以实际页面为准。

是否自动跳转只依据本轮意图，历史用于确定对象：上一轮说「我要修改第一章」，本轮问「那在哪改啊」，仍只提供章节编辑按钮。学生、教师和管理员追问沿用同样规则。多个可能对象先澄清；纯知识解释无需强制生成按钮。

例如学生说「我要做顺序题目」会打开「智能练习」并选择顺序模式；有未完成练习时保留原继续/重新开始选择。教师说「把第一章改名为绪论」会查询当前课程的章节，打开该章节的「详情 / 管理」并填写名称；教师说「给刘欣然发私信，内容是……」会核对本课程学生，打开其私信窗口并回填原文。最后的保存、发送、加入课程、正式导入仍需用户在目标界面点击确认。

「我要做错题」会打开错题重练的题目，有未完成进度则直接继续；「查看错题本」只打开列表。指定章节或知识点的顺序练习会点击对应的练习入口，遇到未完成存档时保留选择，不擅自覆盖进度。重复点击已选练习页签不重绘，过期模式/章节/组卷请求不会覆盖当前界面。

学生、教师明确说「帮我生成学情报告」会在当前课程使用原页面生成动作，完成后刷新归档并打开报告详情；询问「在哪里生成」或要求「只打开配置，先别生成」不会生成。学生生成本人报告，教师生成课程报告；管理员没有教学报告入口。报告生成允许正常写入现有 reports 表，不加表、不加列。教师报告的日期/章节目前只记录在元信息，未参与实际统计，沿用既有能力。

当前执行清单登记 93 个入口：三端全部侧栏页面、加入/切换/新建课程、邀请码、通知、练习模式和指定章节/知识点、错题筛选/详情、资源/图谱/学情面板、报告实际生成/配置/详情/导出位置、教师私信/学生详情/预警复核、题库排序/新建/编辑/草稿/导入、目录章节/知识点/资源、图谱详情/目录、管理员账号搜索/新建/编辑/删除确认/导入，以及聊天输入和历史。删除确认只打开弹窗，不填写确认用户名、不执行删除。未登记的细节仍可由源码索引解释并给所在页面入口；不能宣称任意新增按钮都会自动接通执行。

自动操作不包括代选答案、提交练习、刷分或伪造学习进度。只提出这类要求时简短拒绝，不擅自打开其他页面；普通题目讲解仍可提供。页面清单也不会向模型提供提交答案的入口。

## 实现位置

- `backend/app/agent_st/agent/system_features.yaml`：按角色和真实页面维护标题、别名、位置、步骤、前提、限制与代码锚点。
- `system_code_index.py`：从三端 HTML 读取当前导航和实际加载的脚本，按角色建立界面源码片段索引；从 `Router.register` 对应页面定位代码，排除未加载的旧文件、已移除页面、API 总文件和第三方脚本。公共聊天、弹窗与登录脚本按实际加载范围检索。
- `system_guide.py`：提示词提供当前角色的页面目录，`get_system_guide` 根据完整问题检索实时源码；原手册作为经代码锚点核对的补充，仍兼容已有功能 id。角色从服务端上下文取，不接受模型指定角色或文件路径。
- `tools/analytics.py`：注册 `get_system_guide` 只读工具；`suggest_action` 按角色验证页面，教师和管理员不能生成学生练习动作。
- `loader.py`、`flows/explain.yaml`、`flows/admin_ops.yaml`、`skills/system_guide.md`：区分系统操作、业务数据查询与课程讲解。系统操作使用手册，课程讲解继续检索教材；仅一次输出最终步骤。
- `runtime.py`：本轮成功查到操作手册时，不把使用帮助误判为课程越界；SDK 运行层复用该判断与提示词。
- `assets/js/admin/views/assistant.js`：接通管理员两页导航；师生沿用现有导航配置。共享聊天组件沿用 `tool_log` 重建历史建议按钮。

本次新增只读 `POST /api/v1/question/import/preview`；管理员现有账号导入预览/提交接口复用已有共享解析器，补齐 CSV/TXT 文件支持。数据库表和列不变，SSE 事件名称及字段不变。具体界面准备通过原有 `tool_end.preview` 返回计划，存入现有 `chat_messages.tool_log` 的 `kind=ui_action`；旧 `suggest_action` 页面导航仍兼容。正式业务保存沿用页面原接口，现有后台写操作审批保持原流程。

### 题目与账号内容准备

教师「题库管理」新增「导入题目」入口，支持 TXT/Markdown/JSON/CSV/XLSX/DOCX/有文本层的 PDF。智能体可把本轮文件恢复到文件输入框，或填入结构化题目/文字；解析预览不写库。支持单选、多选，展示题干、选项、答案、解析与校验错误；统一章节/知识点可在预览窗口选择。修改题干、答案、解析或归属后必须重新解析，校验通过才能点击「确认导入题库」；默认导入为待审核。更完整字段可在 JSON 文本中修改。图片需视觉模型先整理为题目内容，不直接当文本文件解析；扫描 PDF 没有新增 OCR，缺失答案和复杂题图不会被自动补造。

管理员明确要求预览时可携带 XLSX/DOCX/CSV/TXT 账号表；文字名单由模型按用户已提供数据整理成带表头 CSV，放入实际导入向导。仍使用原有校验、预览和确认提交。正式通过智能体录入/删除继续走现有审批工具，不重复排入前端和后台两条执行路径。

### 执行机制与保护

- `assets/agent-ui-actions.json` 是前后端共用的真实入口、固定选择器和字段清单；`ui_actions.py` 每次读取校验内容指纹。模型只能选 target/填写允许字段，不能提交任意 JavaScript、选择器或接口。
- `prepare_ui_action` 按服务端角色、当前课程成员关系和对象归属校验，重名返回选择列表；章节/知识点归属和导入题目格式也校验。该工具无业务写权限，学生仍拿不到任何后台写工具。
- `get_system_guide` 只查位置，不产生按钮。三端提示词、流程与工具说明统一要求：目标明确且有可执行入口的操作询问，必须在最终回答前成功准备 `prepare_ui_action`；不能仅写「下方按钮」或编造链接。失败或需要选择时如实说明，不声称入口已生成。
- `assets/js/shared/agent-ui.js` 调用实际 Router、页面处理器和固定按钮，等待异步 DOM 后回填，附件使用 File/DataTransfer。切换账号/课程/页面取消待执行操作；有未保存表单时提示先处理。历史按钮手动重开，刷新不自动重放；停止生成不执行自动计划；同轮多个明确目标只自动打开最后一个。
- 报告实际生成入口仅接受 auto=true 的明确请求；询问使用独立的生成入口/配置入口。执行器仅登记学生和教师的报告生成处理器，配置回填结束后才执行。生成计划在 sessionStorage 记录 started/done/failed，同一计划重复点击或刷新后不再生成；需要新的报告重新提出请求或手动使用页面生成按钮。页面生成期间禁用按钮并复用正在处理的请求；报告请求返回时若已换登录/课程/页面，不弹出旧报告。
- 页面、按钮和文案源码改动下次检索即更新；执行清单修改下次工具调用与前端操作读取新版本。新增可自动操作功能仍需登记执行器，不执行索引里任意代码。部署需同步发布 HTML、JS、JSON 与后端。

## 后续维护

默认启用源码索引。后端启动后首次构造操作提示词或调用工具时构建；后续每次操作查询先校验实际加载文件的 SHA256 指纹，只重新切片变动文件。无需遍历整个仓库或重新索引课程资源。内容指纹能识别同大小、保留修改时间戳的覆盖保存，不能只依赖 Windows 文件时间。

已有页面的按钮、弹窗及文案修改，在下一次操作查询生效，不必维护功能编号或重启索引。新 JS 文件只有被对应 HTML 加载、注册到当前可见页面后才纳入；移除脚本引用或删除文件后旧片段立即失效。新增页面仍需同步现有前后端导航白名单，索引不自动授予新的操作权限。修改 Python 后端本身仍遵循服务器的重载/重启流程；已经显示的历史回答不自动重写。

缓存保存到 `backend/app/data/st/system_code_index.json`（或自定义 `AGENT_DATA_DIR`），已加入 `.gitignore`。缓存是可重建产物，不改业务数据库；缓存内容损坏会从实际源码重建，缓存不可写时使用当前内存索引。部署时需要保留三端 HTML 和上述 JS 源码。源码不可用时明确标记 `manual_fallback`，不能声称原手册反映了最新界面。

这次试用采用文本源码片段检索，不执行 JavaScript，也不是浏览器截图或完整语义分析。模型需继续查询按钮 id、事件选择器、函数名来核对渲染和调用链；单独命中模板、注释、未调用函数不能证明该功能可用。旧手册保留演示入口和业务限制说明；回答优先采用当前源码，旧手册修改后仍需重启以刷新其缓存。

本机源码副本测试：31 个文件、296 个角色源码片段，首次构建约 121 毫秒，复用查询中位数约 42 毫秒；这仅是本机检索耗时，不含模型生成时间，也不保证部署机器速度相同。
