# 后端对接指南

> 目标读者：后端开发者。
> 本指南说明前端的取数方式、接口优先级清单、请求/响应/错误码约定、联调步骤与注意事项。
> **当前前端 `api.js` 已固定 `mode='http'`，默认直连真实后端 `/api/v1`**——无需任何切换即可联调。

---

## 1. 现状：前端已直连真实后端

- 前端所有取数走 `API.*`，`api.js` 的 `config.mode = 'http'`，请求发往 `baseURL + path`（`/api/v1/...`）。
- `GET` 参数拼 query，`POST/PUT/DELETE` 用 JSON body，并自动注入 `Authorization: Bearer <token>` 头。
- 早期 mock 数据（`assets/js/mock/data.js` + `mode:'mock'`）已下线，**不再作为兜底**。后端未实现或返回结构不符时，页面会直接报错，不会回退到假数据——这倒逼后端返回结构必须与文档一致。
- 登录后 JWT 写入 `localStorage.ca_session`，后续请求自动带上。

## 3. 请求 / 响应 / 错误码约定

### 3.1 统一响应信封（所有接口）
```json
{ "code": 0, "message": "success", "data": { }, "traceId": "svc-xxxx" }
```
- `code === 0` 表示成功；前端读取 `data`。
- `code !== 0` 表示业务失败，前端展示 `message`（中文）。
- 全局异常处理器已在 `main.py` 兜底（HTTP 仍返回 200，信封 `code=500`）。

### 3.2 鉴权头
```
Authorization: Bearer <JWT>
```
- 受保护接口缺失 / 失效 token 返回 `401`，建议信封 `code` 用非零（如 401）并在 `message` 说明。
- 身份（userId / role）由后端从 JWT 解析，**请勿依赖**前端在 query/body 重复传 userId。

### 3.3 错误文案
- 登录失败：`账号不存在` / `密码错误，请重试`（前端据此区分提示）。
- 找回密码：`账号不存在` / `新密码至少 6 位`。
- 其他异常：返回可读中文 `message`，前端通过 `Toast` 直接展示，不做二次翻译。

### 3.4 列表分页
列表类接口统一返回：
```json
{ "total": 120, "list": [ ... ] }
```
支持 `page`（从 1 起）、`size`；筛选参数见各接口文档。
> **特例**：`GET /teacher/classes` 返回**裸数组** `[{classId,name}]`（非 `{list}`），前端已兼容。新增接口请勿混用两种形态。

### 3.5 内容类型
- `POST/PUT/DELETE` 用 `application/json` body。
- `GET` 参数拼 query。

## 4. 联调方式

### 4.1 启动后端（推荐，自带前端静态挂载）
```bash
cd backend
pip install -r requirements.txt && pip install bcrypt==4.0.1
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 浏览器打开 http://127.0.0.1:8000/  （登录页）
# 用演示账号 student/123456 进学生端；teacher/123456 进教师端
```
后端会在同一端口挂载前端静态文件，避免跨域，且无需单独起静态服务器。

### 4.2 单独起前端静态服务（可选）
```bash
cd course-agent
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/ ，但需后端在 8000 端口运行供接口调用
```

### 4.3 自测 checklist
- [ ] 登录成功写入会话并跳对应端；错误账号/密码有正确提示。
- [ ] 未登录直接访问 `student.html` / `teacher.html` 被守卫跳回登录页。
- [ ] 三图谱、驾驶舱、热力图、学情矩阵正常渲染（无控制台报错）。
- [ ] AI 答疑返回 `content` + `citations`；越界问题返回 `outOfScope` 降级。
- [ ] 练习流程（组卷→作答→判分→报告）闭环。
- [ ] 教师端班级切换后数据随之刷新。
- [ ] 找回密码（已登录重置本人）后可正常登录。

### 4.4 回归测试
```bash
cd backend
python regression_test.py    # 覆盖登录、学生/教师核心接口、鉴权 401 等约 20 项
```
> 新增接口后建议补回归用例；测试真实读写库，跑完注意清理/重置演示数据。

## 6. 常见问题

**Q：前端一直报接口错误 / 空白？**
A：确认后端已在 8000 端口运行、`/health` 正常；浏览器控制台 Network 面板查看请求是否发往 `/api/v1`、返回结构是否对齐 `数据模型与Mock说明.md`。

**Q：接口返回了数据但页面空白 / 报错？**
A：多为 `data` 字段结构与 `数据模型与Mock说明.md` 不一致（缺字段或数组/对象错位）。按该文档 §3「强依赖字段路径」逐项核对。

**Q：列表接口分页不生效？**
A：确认返回 `{ total, list }` 结构，且分页参数名用 `page`/`size`（除 `/teacher/classes` 裸数组特例）。

**Q：登录后请求 401？**
A：检查 `Authorization` 头格式为 `Bearer <token>`，token 未过期；前端 `API.config.token` 已在登录后更新。

**Q：需要支持 SSE 流式答疑吗？**
A：非必须。当前前端调用一次性 `POST /ai/chat`；流式 `POST /ai/chat/stream` 已留路由，后续可平滑替换。
