# 课件在线预览部署

## 使用方式

教师在「课程资源管理」或「课程目录」选择「课件」，上传 PDF、PPT 或 PPTX。PPT/PPTX 自动生成 PDF，学生在资源中心或图谱关联资源中直接阅读；支持放大全屏、退出全屏、页码跳转和续看。「全屏阅读」位于 PDF 弹窗标题栏右上角、关闭按钮旁，全屏后变为「退出全屏」；阅读窗口中的「下载原文件」始终提供教师上传的原件。更新前端后可按 `Ctrl+F5` 硬刷新，再打开 PDF。

PDF 是静态预览，不保留 PPT 动画、音频和交互。复杂排版可能受服务器字体影响；后端应安装课件使用的字体，部署到 Linux 时尤其需要中文字体。

## 后端依赖

**只在运行后端的电脑或服务器安装 LibreOffice，学生和教师的浏览器设备无需安装。** 无需向 Conda 环境安装转换相关 Python 包，也不依赖 Microsoft Office。

Windows：从 [LibreOffice 官网](https://www.libreoffice.org/download/download-libreoffice/)下载安装，保留 Impress 组件。默认安装目录会自动识别。自定义安装位置时，在 `backend/app/.env` 添加以下配置并重启后端：

```dotenv
LIBREOFFICE_PATH=C:/Program Files/LibreOffice/program/soffice.com
PRESENTATION_CONVERT_TIMEOUT=120
```

Linux：安装发行版提供的 LibreOffice Impress 与所需字体；让 `soffice` 或 `libreoffice` 位于后端进程的 PATH 中，也可以通过 `LIBREOFFICE_PATH` 设置可执行文件绝对路径。后端进程需要临时目录和课程资源目录的读写权限。

Windows 可先检查软件是否可执行：

```powershell
& 'C:\Program Files\LibreOffice\program\soffice.com' --version
```

转换使用官方 [命令行参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html)及 `pdf:impress_pdf_Export` 导出过滤器。每次转换使用独立临时配置目录，与桌面 LibreOffice 隔离；单进程最多同时转换两份课件，默认超时 120 秒，超时回收本次转换进程。

## 存储与错误处理

```text
resources/{course_id}/{res_id}/课件.pptx
resources/{course_id}/{res_id}/课件.pptx.preview.pdf
```

数据库继续保存原件 URL，预览路径由原件 URL 推导，不新增表或字段。删除资源同时删除原件与预览；资源一致性清理会将派生 PDF 视为同一资源。RAG 使用生成的 PDF 入库。

未安装转换器、超时、加密或损坏导致转换失败时，本次上传不会新增资源记录或发布文件；前端显示错误并允许重试。可以改传自行导出的 PDF。历史 PPT 不会自动批量转换，没有预览时仍提供原件下载，教师重新上传即可生成预览。
