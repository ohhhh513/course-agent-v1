# 课程智能体系统 · 接口文档（API v1）

> 适用范围：学生端与教师端前端原型（`course-agent/`）。
> 本文档与 `assets/js/api.js` 中的接口契约 **一一对应**：当前前端 `api.js` 已固定 `config.mode='http'`，页面只通过 `API.*` 取数并**直连真实后端** `/api/v1`，无需改动任何页面代码。（早期 `mock` 模式与 `assets/js/mock/data.js` 已下线。）

---

## 1. 约定

### 1.1 基础信息
| 项 | 值 |
| --- | --- |
| Base URL | `/api/v1`（http 模式） |
| 协议 | HTTPS / HTTP |
| 字符集 | UTF-8，Content-Type: `application/json` |
| 鉴权 | `Authorization: Bearer <JWT>`，由 `/auth/login` 返回 |

### 1.2 统一响应信封
所有接口（含 mock 模式）返回如下结构，页面统一读取 `data` 字段：

```json
{
  "code": 0,
  "message": "success",
  "data": { },
  "traceId": "mock-1693296000000"
}
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 非 0 | 业务异常，`message` 携带错误信息 |

### 1.3 Mock / 真实后端切换
```js
// assets/js/api.js
const config = {
  mode: 'mock',          // 'mock' 走本地模拟数据；'http' 走真实后端
  baseURL: '/api/v1',
  token: 'Bearer <JWT>',
  latency: [120, 380]    // mock 模拟网络延迟(ms)
};
```
- `mode='http'` 时，`GET` 参数拼接到 query，`POST/PUT/DELETE` 使用 JSON body，鉴权头自动注入。
- AI 答疑流式场景建议采用 SSE：`POST /ai/chat/stream`（见第 4 节）。

## 2. 认证与公共

### 2.1 登录
`POST /auth/login`
```jsonc
// request
{ "username": "T100286", "password": "******", "role": "teacher" }
// response.data
{ "token": "mock-jwt-token", "user": { /* 见下方 User */ } }
```

### 2.2 获取当前用户
`GET /auth/profile?role=teacher`
```jsonc
// response.data → User
{ "userId":"T100286","name":"李文博","title":"副教授",
  "dept":"计算机科学与技术学院","role":"teacher",
  "classes":[ { "classId":"CL2301","name":"计算机 2301 班","studentCount":42 } ] }
```

### 2.3 课程基本信息
`GET /course/{courseId}`（默认 `C2026DS001`）
```jsonc
// response.data → { courseId, courseName, semester, teacher, ... }
```

### 2.4 找回密码
`POST /auth/reset-password`（前端页面：`forgot.html`）

> 说明：当前后端实现要求**已登录**且只能重置**当前登录账号**的密码（`req.username` 必须等于当前登录用户）；密码长度建议 ≥ 6，不足返回 `新密码至少 6 位`。公开页的「免登录找回」尚未接入；正式环境应叠加短信 / 邮箱验证码、安全问题等二次校验。

```jsonc
// request
{ "username": "student", "password": "newPass123" }
// response.data
{ "ok": true }
```
| 校验失败 | 返回 message |
| --- | --- |
| 账号不存在 | `账号不存在` |
| 新密码过短（<6） | `新密码至少 6 位` |

### 4.5 AI 智能答疑
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/ai/methods` | 可用教学法列表 |
| GET | `/ai/sessions` | 历史会话列表 |
| GET | `/ai/sessions/{sessionId}/messages` | 会话消息（含溯源引用 citations） |
| GET | `/ai/suggest-questions` | 猜你想问（基于薄弱点 + 高频问题） |
| POST | `/ai/chat` | 发起提问（见下方） |
| POST | `/ai/chat/stream` | **建议**：SSE 流式答疑 |
| POST | `/ai/feedback` | 点赞/点踩，用于知识库迭代 |

`POST /ai/chat` 请求与响应：
```jsonc
// request
{ "sessionId":"new", "question":"Dijkstra 为什么不能处理负权边？", "method":"guided", "kpId?":"KP52" }
// response.data
{ "messageId":"MSG1693296", "method":"guided",
  "content":"<p>...</p>",                 // 支持 HTML 片段
  "citations":[ { "source":"第5章 图（下）课堂课件", "locator":"P28",
                  "quote":"若图中所有边的权值均为非负值…", "kp":"最短路径 Dijkstra" } ],
  "outOfScope":false, "sourceCount":2 }
```
> **严格溯源约束**：当提问超出课程材料范围时，返回 `outOfScope:true` 与降级文案，不输出推测性答案（前端据此展示「转人工」入口）。

### 4.6 智能练习 / 题库
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/practice/modes` | 练习模式（含推荐题量） |
| POST | `/practice/sessions` | 创建练习会话（组卷）：`{mode:'weak\|order\|random\|wrong', kpIds?, count, difficulty?}` |
| GET | `/practice/sessions/{sessionId}/questions` | 取题 |
| POST | `/practice/answers` | 提交单题：`{sessionId,qId,answer,durationSeconds}` → 即时判分 + 解析 + 知识点定位树 |
| POST | `/practice/sessions/{sessionId}/finish` | 结束练习，返回练习报告 |
| GET | `/practice/wrong-book?mastered=true\|false&errorType=&page=` | 错题本 |
| DELETE | `/practice/wrong-book/{qId}` | 移出错题本（标记掌握） |

### 5.4 AI 出题与题库管理
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/question/gen/config` | 出题配置项（素材 / 知识点 / 题型） |
| POST | `/question/materials` | 上传教材/课件/视频并异步解析：`{name}` → `{fileId,status,progress}` |
| POST | `/question/gen` | AI 生成习题：`{materialIds[],kpIds[],types[],difficulty,count,skillId?,requirement?}` → `{taskId,count,questions[],usedSkill,elapsedMs}` |
| GET | `/question/bank?kpId=&type=&status=pending\|approved\|published\|archived&difficulty=&keyword=&page=` | 题库列表 |
| PUT | `/question/{qId}` | 编辑习题（人工校验后修正） |
| POST | `/question/review` | 批量审核发布：`{qIds[],action:'approve\|reject\|publish'}` |
| DELETE | `/question/{qId}` | 删除习题 |
| POST | `/question/import` | 批量导入（Excel/Word）→ `{taskId,total,success,failed}` |

## 7. OpenAPI 3.0 规范（节选）

```yaml
openapi: 3.0.3
info:
  title: 课程智能体系统 API
  version: v1
servers:
  - url: /api/v1
security:
  - bearerAuth: []
components:
  securitySchemes:
    bearerAuth:
      type: http
      scheme: bearer
  schemas:
    Envelope:
      type: object
      properties:
        code: { type: integer, example: 0 }
        message: { type: string, example: success }
        data: { type: object }
        traceId: { type: string }
    ChatRequest:
      type: object
      required: [question, method]
      properties:
        sessionId: { type: string }
        question: { type: string }
        method: { type: string, enum: [lecture, guided, case, heuristic, fun] }
        kpId: { type: string }
    ChatResponse:
      type: object
      properties:
        messageId: { type: string }
        content: { type: string }
        citations:
          type: array
          items:
            type: object
            properties:
              source: { type: string }
              locator: { type: string }
              quote: { type: string }
              kp: { type: string }
        outOfScope: { type: boolean }
paths:
  /auth/login:
    post:
      summary: 账号密码登录
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                username: { type: string }
                password: { type: string }
                role: { type: string, enum: [student, teacher] }
      responses:
        '200':
          description: 成功
          content:
            application/json:
              schema: { $ref: '#/components/schemas/Envelope' }
  /auth/reset-password:
    post:
      summary: 找回密码（校验账号后重置）
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [username, password]
              properties:
                username: { type: string }
                password: { type: string, minLength: 6 }
      responses:
        '200':
          description: 重置成功
          content:
            application/json:
              schema:
                allOf:
                  - $ref: '#/components/schemas/Envelope'
                  - type: object
                    properties:
                      data: { type: object, properties: { ok: { type: boolean } } }
  /ai/chat:
    post:
      summary: AI 智能答疑
      requestBody:
        required: true
        content:
          application/json:
            schema: { $ref: '#/components/schemas/ChatRequest' }
      responses:
        '200':
          description: 答疑结果（含溯源引用）
          content:
            application/json:
              schema:
                allOf:
                  - $ref: '#/components/schemas/Envelope'
                  - type: object
                    properties:
                      data: { $ref: '#/components/schemas/ChatResponse' }
  /teacher/heatmap:
    get:
      summary: 知识点 × 学生 掌握热力图
      parameters:
        - { name: classId, in: query, schema: { type: string } }
        - { name: dimension, in: query, schema: { type: string, enum: [day, week, month] } }
      responses:
        '200': { description: 热力图数据, content: { application/json: { schema: { $ref: '#/components/schemas/Envelope' } } } }
  /question/gen:
    post:
      summary: AI 生成习题
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                materialIds: { type: array, items: { type: string } }
                kpIds: { type: array, items: { type: string } }
                types: { type: array, items: { type: string } }
                difficulty: { type: integer }
                count: { type: integer }
                skillId: { type: string }
      responses:
        '200': { description: 生成结果, content: { application/json: { schema: { $ref: '#/components/schemas/Envelope' } } } }
  /intervention/{ivId}/confirm:
    post:
      summary: 确认执行干预
      parameters: [ { name: ivId, in: path, required: true, schema: { type: string } } ]
      responses:
        '200': { description: 已确认, content: { application/json: { schema: { $ref: '#/components/schemas/Envelope' } } } }
  /report/generate:
    post:
      summary: 一键生成学情报告
      responses:
        '200': { description: 报告已生成, content: { application/json: { schema: { $ref: '#/components/schemas/Envelope' } } } }
```

> 完整 60+ 接口的 YAML 可依据第 2~5 节逐项补齐；当前节选已覆盖鉴权、AI 答疑、热力图、AI 出题、干预、报告六大高频链路。

## 8. 前端对接说明
- 所有取数统一走 `assets/js/api.js` 的 `API.<module>.<method>(payload)`。
- 当前已 `mode='http'` 直连真实后端，页面零改动；`mock` 模式已下线，请勿回退。
- 实时性：预警从产生到触达控制在分钟级（`/teacher/alerts` 的 `createdAt` 与顶栏 `updatedAt` 体现）。
- 可解释性：AI 答疑、AI 出题均返回 `citations`/`sourceRef`，前端以折叠卡片展示原文溯源，未命中课程材料时按「严格溯源」约束降级。
