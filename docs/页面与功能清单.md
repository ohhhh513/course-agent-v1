# 页面与功能清单

> 适用对象：后端开发者（了解前端需要哪些数据）、产品经理、测试。
> 每个页面列出：角色、入口文件、核心视图/区块、调用的接口（对应 `接口文档.md`）。
> 当前共 **14 个页面**：学生端 7 个 + 教师端 7 个。

---

## 1. 公共页（无需登录）

### 1.1 `index.html` — 登录页（站点首页）
- **角色**：匿名
- **功能**：账号 / 密码登录（学生 / 教师 / 管理员三种角色切换，支持 `?role=` 预选）；「忘记密码？」链接跳 `forgot.html`；提示"账号由管理员创建，初始管理员 admin/admin"（前端不内置演示账号）。
- **调用接口**：
  - `POST /auth/login`
  - `POST /auth/reset-password`（经 `forgot.html`，需已登录且只能重置当前账号）

### 1.2 `forgot.html` — 找回密码
- **角色**：匿名
- **功能**：输入账号 + 新密码 + 确认，重置密码后回登录页。
- **调用接口**：`POST /auth/reset-password`
- **注意**：当前后端实现要求**已登录**且只能重置**当前登录账号**的密码（见 `鉴权与会话方案.md` §3.3）。

### 1.3 `home.html` — 产品介绍 / 双角色入口（可选）
- **角色**：匿名
- **功能**：展示系统价值与双端能力卡片；点击角色卡经 `Auth.enter(role)` 跳登录页（带角色预选）。
- **调用接口**：无（纯展示）

## 2. 学生端 `student.html`（需登录，7 个视图）

顶栏：`#updateTag`（数据更新时间）、消息按钮（`#msgBtn`，拉取 `GET /student/messages`）、

## 4. 页面级交互与接口依赖汇总

| 触发动作 | 前端行为 | 接口 |
| --- | --- | --- |
| 用户首次访问业务端 | 路由守卫检测会话 → 跳登录 | — |
| 登录成功 | 写会话、注入用户信息、跳对应端 | `/auth/login` |
| 切换学生/教师端内班级 | 重新拉取监测数据 | 各 `*?classId=` |
| AI 答疑发送问题 | 调用答疑并渲染溯源卡片 | `/ai/chat` |
| 开始练习 | 组卷 → 取题 | `/practice/sessions` + `/questions` |
| 提交单题 | 判分 + 解析 | `/practice/answers` |
| 结束练习 | 报告 | `/practice/sessions/{id}/finish` |
| 上传素材出题 | 异步解析 → 生成 | `/question/materials` + `/question/gen` |
| 确认干预 | 执行 | `/intervention/{ivId}/confirm` |
| 生成报告 | 生成 → 详情 | `/report/generate` + `/report/{id}` |

## 5. 给后端的「前端需要什么」清单

1. **学生端**需要：驾驶舱聚合、三图谱、资源、AI 答疑、练习与错题、学情矩阵/雷达/成长/对比、预警与消息。
2. **教师端**需要：驾驶舱、监测看板（热力图/学生/个体/预警/私信）、归因分析、AI 出题与题库、干预策略、报告、资源管理。
3. 所有列表接口建议支持分页（`page`/`size`）与筛选参数（见各接口文档）。
4. 实时性要求：预警从产生到教师端触达控制在分钟级（`updatedAt` 体现）。
5. 可解释性：AI 答疑、AI 出题必须返回 `citations` / `sourceRef` 溯源字段。
