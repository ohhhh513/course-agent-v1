# 页面与功能清单

> 适用对象：后端开发者（了解前端需要哪些数据）、产品经理、测试。
> 每个页面列出：角色、入口文件、核心视图/区块、调用的接口（对应 `接口文档.md`）。
> 当前侧栏共 **18 个页面**：学生端 8 个 + 教师端 8 个 + 管理员端 2 个。
> 连续追问按最近对话确定对象：例如「那他的资源在哪里」提供对应知识点关联资源按钮；是否自动跳转只看本轮，询问给按钮，明确要求打开才跳转。多个可能对象先澄清，纯知识讲解不强制导航。
> 三端智能体按角色检索实际加载的界面源码，并提供已登记的 93 个精确入口：询问给按钮，明确指令打开具体页签/弹窗/对象，回填文字与适用附件。做错题会打开题目或续练，指定章节/知识点会打开对应顺序题目；师生明确生成报告会实际生成并打开详情，询问或仅配置不生成。禁止代答、自动提交答案及伪造进度；保存、发送、加入和正式导入仍由用户确认。教师题库新增只读导入预览，管理员导入向导支持 XLSX/DOCX/CSV/TXT。源码修改下次查询更新；新增可执行入口需同步 `assets/agent-ui-actions.json` 和执行器。`system_features.yaml` 保留为限制补充与故障回退。维护、验证与分步回退见 [智能体系统操作指南](智能体系统操作指南.md)；下方旧功能表保留部分历史接口说明。

## 1. 公共页（无需登录）

### 1.1 `index.html` — 登录页（站点首页）
- **角色**：匿名
- **功能**：账号 / 密码登录（学生 / 教师 / 管理员三种角色切换，支持 `?role=` 预选）；「忘记密码？」链接跳 `forgot.html`；提示"账号由管理员创建，初始管理员 admin/admin"（前端不内置演示账号）。
- **调用接口**：
  - `POST /auth/login`
  - `POST /auth/reset-password`（经 `forgot.html`，需已登录且只能重置当前账号）

### 1.2 `forgot.html` — 找回密码
- **角色**：匿名
- **功能**：输入账号 + 新密码 + 确认，重置密码后回登录页。
- **调用接口**：`POST /auth/reset-password`
- **注意**：当前后端实现要求**已登录**且只能重置**当前登录账号**的密码（见 `鉴权与会话方案.md` §3.3）。

### 1.3 `home.html` — 产品介绍 / 双角色入口（可选）
- **角色**：匿名
- **功能**：展示系统价值与双端能力卡片；点击角色卡经 `Auth.enter(role)` 跳登录页（带角色预选）。
- **调用接口**：无（纯展示）

## 5. 给后端的「前端需要什么」清单

1. **学生端**需要：驾驶舱聚合、三图谱、资源、AI 答疑、练习与错题、学情矩阵/雷达/成长/对比、预警与消息、**个人学情报告（生成/归档/导出）**。
2. **教师端**需要：驾驶舱、监测看板（热力图/学生/个体/预警/私信）、归因分析、AI 出题与题库、干预策略、报告、资源管理。
