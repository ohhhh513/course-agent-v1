# 页面与功能清单

> 适用对象：后端开发者（了解前端需要哪些数据）、产品经理、测试。
> 每个页面列出：角色、入口文件、核心视图/区块、调用的接口（对应 `接口文档.md`）。
> 当前共 **14 个页面**：学生端 7 个 + 教师端 7 个。

---

## 1. 公共页（无需登录）

### 1.1 `index.html` — 登录页（站点首页）
- **角色**：匿名
- **功能**：账号 / 密码登录；学生 / 教师角色切换；「忘记密码？」链接跳 `forgot.html`；演示账号提示。
- **调用接口**：
  - `POST /auth/login`
  - `POST /auth/reset-password`（经 `forgot.html`，需已登录且只能重置当前账号）

### 1.2 `forgot.html` — 找回密码
- **角色**：匿名
- **功能**：输入账号 + 新密码 + 确认，重置密码后回登录页。
- **调用接口**：`POST /auth/reset-password`
- **注意**：当前后端实现要求**已登录**且只能重置**当前登录账号**的密码（见 `鉴权与会话方案.md` §3.3）。

### 1.3 `home.html` — 产品介绍 / 双角色入口（可选）
- **角色**：匿名
- **功能**：展示系统价值与双端能力卡片；点击角色卡经 `Auth.enter(role)` 跳登录页（带角色预选）。
- **调用接口**：无（纯展示）

## 2. 学生端 `student.html`（需登录，7 个视图）

守卫：`Auth.requireAuth('student')`。侧边栏视图与接口映射：

| 视图 key | 标题 | 功能区块 | 调用接口 |
| --- | --- | --- | --- |
| `dashboard` | 学习驾驶舱 | 概览（进度/连续打卡/今日时长）、核心指标卡、待办清单、薄弱点、猜你想问、最近动态、贡献热力 | `GET /student/dashboard` |
| `graph` | 课程图谱导航 | 知识/问题/目标三图谱切换；节点详情抽屉；推荐学习路径 | `GET /graph?type=`、`GET /graph/kp/{kpId}`、`GET /graph/path` |
| `resource` | 学习资源中心 | 资源列表（视频/PPT/文档/题库），按类型/知识点/关键词筛选 | `GET /student/resources` |
| `ai` | AI 智能答疑 | 教学法选择、对话（含溯源引用）、历史会话、猜你想问、点赞/点踩 | `GET /ai/methods`、`GET /ai/sessions`、`GET /ai/sessions/{id}/messages`、`GET /ai/suggest-questions`、`POST /ai/chat`、`POST /ai/feedback` |
| `practice` | 智能练习 | 练习模式选择 → 组卷 → 逐题作答（即时判分 + 解析）→ 练习报告；错题本与错题详情 | `GET /practice/modes`、`POST /practice/sessions`、`GET /practice/sessions/{id}/questions`、`POST /practice/answers`、`POST /practice/sessions/{id}/finish`、`GET /practice/wrong-book`、`DELETE /practice/wrong-book/{qId}`、`GET /practice/wrong-book/{qId}/detail` |
| `mastery` | 我的学情 | 掌握矩阵（按章分组）、能力雷达、成长轨迹、班级对比 | `GET /student/mastery/matrix`、`GET /student/ability/radar`、`GET /student/growth`、`GET /student/compare` |
| `alerts` | 预警与提醒中心 | 我的预警列表（按等级/状态筛选）、标记已读、私信/系统通知 | `GET /student/alerts`、`PUT /student/alerts/{alertId}/read`、`GET /student/messages`、`PUT /student/messages/{msgId}/read` |

顶栏：`#updateTag`（数据更新时间）、消息按钮（`#msgBtn`，拉取 `GET /student/messages`）、退出按钮（`#logoutBtn`）。

## 3. 教师端 `teacher.html`（需登录，7 个视图）

守卫：`Auth.requireAuth('teacher')`。顶栏含班级切换下拉 `#classSel`（切换后各监测视图按 `classId` 重新取数）。

| 视图 key | 标题 | 功能区块 | 调用接口 |
| --- | --- | --- | --- |
| `dashboard` | 教学驾驶舱 | 班级概览、实时动态流、待办、知识点掌握排行 | `GET /teacher/dashboard` |
| `monitor` | 学情监测看板 | 知识点×学生 掌握热力图；学生列表（筛选/排序）；个体学情详情（画像/时间表/活跃度/答题明细/高频错题）；预警列表与人工复核；向学生私信 | `GET /teacher/heatmap`、`GET /teacher/students`、`GET /teacher/students/{userId}/profile`、`GET /teacher/alerts`、`PUT /teacher/alerts/{alertId}/review`、`POST /teacher/messages` |
| `analysis` | 归因与错题分析 | 错题与归因分析（错误类型分布、高频错题、薄弱链路、成因概率、共性与个性）、AI 归因建议 | `GET /analysis/errors`、`GET /analysis/weak-chain`、`GET /analysis/causes` |
| `question` | AI 出题与题库管理 | 出题配置、上传素材并异步解析、AI 生成习题（当前题库随机兜底）、题库列表、编辑/审核发布/删除/批量导入、生成靶向补练包 | `GET /question/gen/config`、`POST /question/materials`、`POST /question/gen`、`GET /question/bank`、`PUT /question/{qId}`、`POST /question/review`、`DELETE /question/{qId}`、`POST /question/import`、`POST /question/packs` |
| `intervention` | 教学干预与策略 | 干预建议列表（按状态/范围）、确认/自定义执行、忽略、干预前后对比、策略库模板（查看/沉淀） | `GET /intervention/list`、`POST /intervention/{ivId}/confirm`、`POST /intervention/{ivId}/reject`、`GET /intervention/{ivId}/effect`、`GET /intervention/templates`、`POST /intervention/templates` |
| `report` | 学情分析报告 | 历史报告归档、一键生成报告、报告详情（多章节）、导出 PDF/HTML | `GET /report/list`、`POST /report/generate`、`GET /report/{reportId}`、`POST /report/{reportId}/export` |
| `resource` | 资源管理 | 教师端资源列表、按知识点挂载、上传、删除 | `GET /teacher/resources`、`GET /teacher/resources/kps`、`POST /teacher/resources/upload`、`DELETE /teacher/resources/{resId}` |

> 注：原「SKILL 定制」板块已从前端移除，教师端不再有该视图，对应 `/skill/*` 接口不应再被前端调用。

## 4. 页面级交互与接口依赖汇总

| 触发动作 | 前端行为 | 接口 |
| --- | --- | --- |
| 用户首次访问业务端 | 路由守卫检测会话 → 跳登录 | — |
| 登录成功 | 写会话、注入用户信息、跳对应端 | `/auth/login` |
| 切换学生/教师端内班级 | 重新拉取监测数据 | 各 `*?classId=` |
| AI 答疑发送问题 | 调用答疑并渲染溯源卡片 | `/ai/chat` |
| 开始练习 | 组卷 → 取题 | `/practice/sessions` + `/questions` |
| 提交单题 | 判分 + 解析 | `/practice/answers` |
| 结束练习 | 报告 | `/practice/sessions/{id}/finish` |
| 上传素材出题 | 异步解析 → 生成 | `/question/materials` + `/question/gen` |
| 确认干预 | 执行 | `/intervention/{ivId}/confirm` |
| 生成报告 | 生成 → 详情 | `/report/generate` + `/report/{id}` |

## 5. 给后端的「前端需要什么」清单

1. **学生端**需要：驾驶舱聚合、三图谱、资源、AI 答疑、练习与错题、学情矩阵/雷达/成长/对比、预警与消息。
2. **教师端**需要：驾驶舱、监测看板（热力图/学生/个体/预警/私信）、归因分析、AI 出题与题库、干预策略、报告、资源管理。
3. 所有列表接口建议支持分页（`page`/`size`）与筛选参数（见各接口文档）。
4. 实时性要求：预警从产生到教师端触达控制在分钟级（`updatedAt` 体现）。
5. 可解释性：AI 答疑、AI 出题必须返回 `citations` / `sourceRef` 溯源字段。
