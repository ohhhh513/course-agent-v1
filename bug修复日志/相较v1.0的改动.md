## 十、缺陷修复：智能答疑流式输出与 Markdown 渲染 (2026-09-06)

- `assets/js/api.js`（**流式无输出根因**）：`streamRequest` 的 SSE 分块解析原先按 `\n\n` 切事件，而 sse_starlette 按 ASGI 规范发送 `\r\n` 行尾（分隔符为 `\r\n\r\n`），导致整个事件流一个都切不出来、页面无任何实时内容，只能刷新后从库中历史看全文；已改为正则 `/\r?\n\r?\n/` 切块 + `/\r?\n/` 拆行（两种行尾兼容）。
- `backend/app/routers/ai.py`：`/ai/chat/stream` 的 `content` 事件 data 由裸文本改为 JSON 编码 `{"delta": ...}`（delta 内含换行/markdown 符号，裸文本会破坏 SSE 解析与前端 JSON 统一解析）。
- `assets/js/api.js`：`data:` 字段解析由 `trim()` 改为仅去掉字段名后的一个空格，避免丢失 delta 内的前导空格。
- `assets/js/student/views/chat.js`：新增 `mdToHtml()` 轻量 Markdown 渲染（`**加粗**`/`#` 标题/有序无序列表/`` `行内代码` ``/```代码块```/`>` 引用/空行分段），讲解 Agent 的 Markdown 输出不再出现 `**一句话结论**` 等格式符号泄露，且正常分段；流式过程按累积全文重渲染，历史会话消息同样经渲染器（对旧版 HTML 存量消息原样放行，二者兼容）。
- `assets/css/base.css`：新增 `.md-h*`/`.md-list`/`.md-pre`/`.md-quote` 渲染样式。
- 验证：live SSE 实测 423 个 JSON content 事件；Node 模拟前端解析+渲染全链路——662 字正文完整累积、有序列表/分段正确、`**` 泄露 0 处。

## 二十二、缺陷修复：学生驾驶舱「最近学习动态」时间不对 (2026-09-06)

- 成长轨迹周对齐：`backend/app/routers/student.py` 的 `growth` 原来“最旧周=第1周（7/13）”，现改为“**当前周（周一 8/31）= 第1周**”，并把 x 轴标签带上周一日期（`第1周·08/31` … `第8周·07/13`）。验证：第一周周一为 08/31，本周掌握率落在第1周。
