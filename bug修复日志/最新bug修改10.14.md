## 一、教师端出题界面新增试卷测验（2026-10-14）

**前端渲染**

- `assets/js/teacher/views/question.js`：在「题库管理」和「回收站」之间增加「试卷测验」；复用题库同款题目编辑器，支持单选、多选、判断、填空、知识点及配图。

- `assets/js/teacher/views/exams.js`：新增试卷列表、名称搜索、草稿与已发布筛选；支持从题库跨页选题、自己出题、调整题目顺序、编辑和移除；教师自行命名试卷，默认总分 100，自动分配三题为 33、33、34，也可修改总分并手动分配每题分值，最多保留一位小数；实时显示已分配分数，欠分、超分或题目不完整时禁止发布，支持保存草稿、编辑时直接发布及列表发布。题库选题增加章节与知识点筛选并支持组合；章节、知识点和题型下拉框显示向下箭头；搜索结果显示题干、章节和知识点，题干、章节名、知识点名中的关键词高亮；点击题目可看详情，点击旁边按钮加入试卷。

- `assets/css/app.css`：增加选题结果、详情入口、添加按钮及窄屏布局样式。

**后端**

- `backend/app/routers/teacher.py` 的 `GET /question/bank`：增加可组合的章节与知识点筛选；关键词搜索扩展到章节名；保留题目原有响应结构，供试卷选题在全题库范围分页查询。

- `backend/app/routers/teacher_exams.py`、`backend/app/services/exam_papers.py`：新增教师试卷列表、详情、保存和发布接口，校验题目与分值，按教师和课程隔离，防止多个窗口覆盖修改；复用现有 `teacher_class_data` 的 JSON 字段保存试卷快照，正式发布时将新题或在卷内修改的题写入现有题库并标记为已发布，保留原题和历史答题记录。

- `assets/js/api.js`、`backend/app/main.py`：接入试卷接口与路由，并记录题库筛选参数及关键词匹配范围；`teacher.html` 加载试卷测验脚本。

**数据库·数据**

- 未增加或修改数据库表、字段、索引；草稿题目快照使用既有 `teacher_class_data` JSON 字段保存，发布时写入既有 `questions` 表；学生端本次新增试卷测验沿用现有作答表。

**测试**

- `dev_tools/check_teacher_exams.py`：使用数据库副本覆盖章节与知识点组合筛选、章节关键词搜索、草稿持久化、自动与手动分值、四种题型及配图、编辑和列表发布、权限隔离、修订冲突与题目快照；确认草稿新题不入题库，发布后新题进入题库。

- 验证：试卷接口验收、Python 与 JavaScript 语法检查、角色与路由权限检查、MCP 检查均通过；前端完成 1200 组分值组合及保存、发布、保存失败恢复的逻辑检查；智能体真实问答冒烟完成，SDK 不可用，实际回退到 `legacy`。数据库相关验收使用临时副本。当前 Browser 无可用连接，尚未完成浏览器显示、真实点击和硬刷新验收，以上逻辑检查不作为浏览器实测。

## 二、学生端试卷测验（2026-10-14）

**前端渲染**

- `assets/js/student/views/practice.js`、`assets/js/student/views/exams.js`：在「智能练习」和「错题本」之间增加「试卷测验」；展示当前课程教师已发布试卷，支持按知识点筛选、按名称或知识点实时搜索及关键词高亮，并显示总分、题数、上次得分和试卷正确率。

- `assets/js/student/views/exams.js`、`assets/css/app.css`、`student.html`：提供试卷计时、逐题答题与自动保存、断开后继续未完成测验、交卷结果和逐题对错解析、重新测验；退出试卷或切换页面前提示并结算，答对曾错题后同步移出错题本待攻克分类。

**后端**

- `backend/app/routers/student_exams.py`、`backend/app/main.py`：新增学生已发布试卷、开始/继续测验、保存答案和结算接口；按学生身份与当前课程隔离，交卷后写入既有 `practice_sessions`、`answer_records`，将成绩用于正常正确率和错题本统计。

- `assets/js/api.js`：接入学生试卷列表、开始、自动保存和交卷接口；交卷返回试卷成绩、用时及逐题作答情况。

**数据库·数据**

- 未增加或修改数据库表、字段、索引；学生作答与测验快照分别使用既有答题记录、练习会话及 `teacher_class_data` JSON 字段；试卷草稿中的新题不写入题表，正式发布时写入现有 `questions` 表。

**测试**

- `dev_tools/check_teacher_exams.py`、`dev_tools/check_student_exams.py`：分别覆盖教师发布题入库及学生课程隔离、试卷答案脱敏、保存与继续、判分、正确率、错题本同步、重测成绩和重复结算；数据库写入仅在只读复制出的临时库执行。

- 验证：Conda 环境 Python 语法检查、前端 JavaScript 语法检查、`git diff --check`、教师发布入库与学生试卷端到端验收、智能体角色权限、路由角色闸门及 MCP 导出检查通过；数据库测试均在只读复制出的临时库执行。智能体 SDK 冒烟因当前环境 `sdk_runner.available=False` 回退到 legacy 并完成问答；Browser 当前无可用连接，未完成浏览器真实点击与硬刷新验收。
